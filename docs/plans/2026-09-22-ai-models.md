# Multi-model AI settings

Provider owns a shared encrypted API key and a legacy/default model route. Additional model routes have stable local IDs, model IDs, protocol, base URL, enabled state, timeout/retries, output cap and temperature. Existing provider IDs remain the default route; additional routes use provider:model IDs. The same model can be configured on multiple protocols as distinct routes. Global and per-service fallback select routes explicitly. No auto-discovery or live API calls without a configured, allowed host.

UI groups model cards inside provider cards; deleting/disabling removes affected references. Preserve stored settings.

# Top-up popup — approved design

User selected a prominent dark-green wallet card. Cream modal body, gold Point coin, large balance, calm typography. Mobile bottom sheet; desktop centered dialog. Package choices do not create orders. Explicit summary and Continue payment action below; optional promo and history disclosures. Preserve API prices and package labels, no fabricated popularity badges. Support loading/empty/error, guest/preview restrictions, pending creation, applied promo invalidation and network failure. Native dialog focus containment, Escape, close, reduced motion, scrollable body and visible payment footer.

Scope: TopupPanel and scoped styling, focused behavior tests, local/browser verification and frontend production release. No real payment, provider changes, backend/reward changes.
